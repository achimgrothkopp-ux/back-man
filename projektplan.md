----------------------------------------------------------------
Projektplan für eine Backup-Manager anwendung unter Linux (Kali)
----------------------------------------------------------------

Anforderungen:
- grafische Oberfläche / UI 
- Auswahl mehrerer Pfade als Backup-Source möglich
- Auswahl mehrerer Pfade als Backup-Ziel möglich
- Auswahl ob inkrementelles oder Vollbackup
- grafische Fortschrittsanzeige eines laufenden Backups
- Verwaltung alter Backups
- Logging und "Logfile-Management"
- Scheduler-Möglichkeit (Cron / Autostart / ...?)

Entwickelt werden soll in Python3 für den Linux-Desktop (QT)
